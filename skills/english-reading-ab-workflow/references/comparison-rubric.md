# Comparison Rubric

Create a standalone Markdown evaluation report using the following structure.

## 1. Executive conclusion

State the most important difference in two to four sentences. Do not equate length with quality.

## 2. Controlled-test conditions

Record:

- shared source title and number;
- identical source-text condition;
- baseline contract used;
- skilled method used;
- known source uncertainty, if any.

## 3. Dimension comparison

Use a table with these dimensions:

| Dimension | Baseline | Skilled | Evidence-based judgment |
|---|---|---|---|
| Story comprehension | | | |
| Language value | | | |
| Thinking / viewpoint | | | |
| Beyond literal meaning | | | |
| Writing craft | | | |
| Transferable learning assets | | | |
| Active reflection | | | |
| Clarity and reader workload | | | |

Quote only short phrases needed as evidence. Prefer precise paraphrase.

## 4. Skilled gains

List only gains supported by concrete output differences. For each:

- name the gain;
- cite what the skilled output added or connected;
- explain why it helps comprehension or long-term learning.

## 5. Baseline advantages or regressions

Check whether the baseline is:

- more concise;
- clearer in any explanation;
- less repetitive;
- better calibrated to the article;
- more natural in tone.

Record “none observed” when appropriate. Do not assume the skilled output wins every dimension.

## 6. Misses and unnecessary content

Identify:

- important meaning missed by either branch;
- claims that exceed textual evidence;
- repeated points across skilled sections;
- low-value vocabulary or excessive grammar;
- sections whose length exceeds their learning value.

## 7. Improvement candidates

Use this table:

| Candidate | Evidence from this article | Expected benefit | Risk / trade-off | Status |
|---|---|---|---|---|

Status must be one of:

- `Article-specific`
- `Candidate — needs more samples`
- `Validated pattern — eligible for proposed update`

Do not label a pattern validated from one article alone.

## 8. Recommendation

Choose one:

- Keep the companion skill unchanged.
- Observe the candidate across more articles.
- Prepare a separately reviewable skill update proposal.

Never modify the skill from this report alone.

## Evaluation principles

- Correctness outranks completeness.
- Insight outranks section count.
- Transfer value outranks vocabulary quantity.
- A concise baseline can outperform a verbose skilled section.
- A skilled gain must trace to the method, not merely general model variation.
- Recommendations must generalize beyond the current article before becoming skill rules.
