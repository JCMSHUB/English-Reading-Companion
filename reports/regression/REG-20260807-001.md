# REG-20260807-001 · 文化与历史入口词选择回归

## 被测版本

- `english-reading-companion` 2.3.0
- 测试日期：2026-08-07

## 变更目标

当文化、历史或角色身份词是理解文章情境与 stakes 的必要入口时，在 3–5 个重点表达中保留一项；解释只提供解锁正文所需的最小、稳定语境，避免无证据的背景扩写。

## 测试样本

- 003 · *War Bride Runs for Congress*：A/B 对比显示基线保留并解释了 `war bride`，而 2.2.0 技能分支未选取这一历史身份词。
- 005 · *Sometimes Life’s a Rodeo*：A/B 对比显示基线解释了 `rodeo clown and bullfighter`，而 2.2.0 技能分支未选取这一角色入口词。
- `tests/regression/test_skill_version_contract.py`：版本一致性、既有阅读体验契约，以及新增入口词选择与证据边界契约。

## 结果

| 检查项 | 结果 | 证据 |
|---|---|---|
| 版本一致性 | 通过 | `VERSION`、`SKILL.md` 与 `agents/openai.yaml` 均为 2.3.0。 |
| 条件式选择规则 | 通过 | 规则要求“必要时保留一项”，不把文化词变成每篇必填项。 |
| 证据边界 | 通过 | 规则明确最小、稳定语境，并禁止扩写为未经支持的背景史。 |
| 自动回归 | 通过 | `python3 -B -m unittest discover -s tests/regression -v`：8 项通过。 |
| 代表性样本复核 | 通过 | 003 与 005 的 A/B 报告各自记录了同一类漏选，构成此次兼容性增强的依据。 |

## 与上一版本的差异

2.2.0 以可迁移的高价值表达为主；2.3.0 增加了一个受条件约束的选择优先级，防止文章特有的理解入口被通用表达挤出。它不改变四层方法、原文保真规则或既有内容稿。

## 发布建议

建议发布 2.3.0。自动回归、版本一致性、技能 frontmatter 和 UI 元数据均已验证；此为兼容的学习价值能力新增，符合 MINOR 版本规则。

## 已知限制与后续候选

- 两篇样本足以授权本次轻量改进，但还不足以规定何种词必须被选中；仍应收集不同题材的 A/B 样本。
- 若术语的解释需要可变、专业或争议性外部知识，应说明信息边界或保留原文，不应凭记忆补写背景。
