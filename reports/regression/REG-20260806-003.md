# REG-20260806-003 · 隐藏伴读元数据回归

## 被测版本

- `english-reading-companion` 2.0.0
- 测试日期：2026-08-06

## 变更目标

将伴读文件顶部的工程元数据由可见 YAML frontmatter 改为 HTML 注释，避免 Markdown 阅读端将其显示为字段表格。

## 测试样本

- `content/readings/001-let-him-go-olivia.md`
- `content/readings/002-lazy-summers.md`
- 技能版本契约与本地交付规则。

## 结果

| 检查项 | 结果 | 证据 |
|---|---|---|
| 版本一致性 | 通过 | `VERSION`、`SKILL.md` 与 `agents/openai.yaml` 均为 2.0.0。 |
| 隐藏元数据格式 | 通过 | 两份伴读均以 HTML 注释开头，包含完整元数据。 |
| 阅读端隔离 | 通过 | 两份伴读均不含 YAML 分隔符，标题紧随隐藏注释。 |
| 既有技能契约 | 通过 | 回归测试覆盖版本、来源、落盘、覆盖保护与引用文件。 |

## 与上一版本的差异

1.0.1 在文件开头使用 YAML frontmatter；2.0.0 使用不参与正文渲染的 HTML 注释。元数据字段保持不变，读者侧不再显示工程字段表格。

## 发布建议

建议发布 2.0.0。此变更改变了伴读文件的机器读取结构，属于不兼容的格式调整。

## 已知限制与后续候选

- 使用依赖 YAML frontmatter 的外部读取器时，需改为读取 HTML 注释或在导入时转换；本地项目目前没有此类读取器。
