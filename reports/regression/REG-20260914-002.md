## 场景静态走查

以下按完整指令及参考文件推演分支，不是独立模型端到端测试。

| 场景 | 核查结论 |
|---|---|
| 用户只要求翻译一句话 | 不因英语文本自动触发伴读或 A/B。 |
| 用户要求审查两个技能的规则 | 属于技能维护，不自动生成三份 A/B 文件。 |
| 伴读中的单句追问 | 保留该句语境与准确性检查，不要求 3–5 表达、阅读路线或 Replay。 |
| 完整伴读或 A/B skilled | 继续覆盖四层阅读维度、3–5 表达、原文对照和 Replay；只有项目系列进入持续归档。 |
| A/B baseline | 使用基线约定，不强制读取或套用伴读技能及其完整检查。 |
| 新项目文章没有 slug | 按命名规则生成 slug，确定编号，保存新 draft；不单为命名请求确认。 |
| 新文章没有原始标题 | 标记 untitled，按内容生成文件 slug，不伪造原文标题。 |
| 来源身份或覆盖对象确有歧义 | 继续要求必要澄清，不以自主推进为由猜测。 |
| 历史综合时 companion 未安装 | 使用历史样本版本，可继续综合；缺失版本元数据的样本单独排除并报告。 |
| 一篇文章的建议获用户同意 | 可在明确授权范围内采用，但仍是 Candidate，不宣称已获跨样本验证。 |
| 已明确授权评估后实施限定修改 | 完成评估后在授权范围内实施，无需重新索取同一授权。 |
| 用户只要求比较 | 只交付评估，不自动修改技能。 |
| 完整项目新稿符合得到大脑持续授权 | 保留同文件、私密、动态知识库 ID、幂等与业务成功检查，无需逐篇确认。 |

对第 3 项另做两个微型文本的规则推演：

- 自拟直白文本 `The library opens at nine. I arrived at ten and borrowed a book.` 只提供时间及借书事件，没有充分依据添加讽刺、隐喻或人生寓意；新规则允许无额外隐含意义发现。
- 自拟语境 `I told her I still got nervous before speaking. She said, “You're in good company. I do too.”` 支持解释共同经历带来的安慰；新规则仍要求解释这一语境含义，不把“取消凑数”误解为省略必要分析。

两个微型文本用于检查规则是否同时容纳“没有隐藏含义”和“确有语境含义”，不是代表性文章重生成，不能据此声称实际伴读质量已提高。
