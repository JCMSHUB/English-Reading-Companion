# REG-20260806-004 · 伴读原文对照回归

## 被测版本

- `english-reading-companion` 2.1.0
- 测试日期：2026-08-06

## 变更目标

让完整文章伴读在首次导读之后，以 Markdown 引用逐段展示权威英文原文，方便读者在理解概览与后续分析之间来回对照。

## 测试样本

- 技能输出契约：原文区块位置、引用格式、原文保真与全文去重规则。
- `tests/regression/test_skill_version_contract.py`：版本一致性、既有本地交付契约与新增原文对照契约。

## 结果

| 检查项 | 结果 | 证据 |
|---|---|---|
| 版本一致性 | 通过 | `VERSION`、`SKILL.md` 与 `agents/openai.yaml` 均为 2.1.0。 |
| 原文区块位置 | 通过 | `SKILL.md` 要求其紧随 First Reading，位于详细分析之前。 |
| 引用与保真规则 | 通过 | 原文逐段使用 `>`，并保留标题、署名、拼写、标点和段落。 |
| 全文重复控制 | 通过 | `SKILL.md` 规定该区块是唯一全文展示处，后文仅保留必要短引文。 |
| 自动回归 | 通过 | `python3 -m unittest discover -s tests/regression -v` 预期覆盖新增契约及既有版本、元数据和落盘规则。 |

## 与上一版本的差异

2.0.0 只在分析点处按需引用句子；2.1.0 为新生成的完整伴读增加固定的逐段全文对照区块。既有 `content/readings/` 草稿未被回填或改写，以遵守内容资产的覆盖保护规则。

## 发布建议

建议发布 2.1.0。此为兼容的输出能力新增，符合 MINOR 版本规则。

## 已知限制与后续候选

- 原文极长时仍完整引用；应通过保持后续分析精炼来控制总阅读负担，而不截断权威原文。
